Case study · Ketsol · Ketsol Manufacturing Suite (KMS)

Shop-floor data, from PLC to dashboard

KMS is Ketsol's own data concentrator and visualization product. I built the machine connectors, the time-series store and the dashboard builder that let plant users make their own reports.

The problem

Plant machines speak different protocols, and their data rarely reaches the people who need it. Every new report needed a developer, and nobody was told about problems on the line in real time.

What I built

  • Python connectors for OPC UA, Modbus TCP and MQTT, tested against simulators and live PLC connections.
  • InfluxDB time-series store running in Docker, holding machine data as it streams in, with RabbitMQ moving messages between services.
  • Drag-and-drop report and dashboard builder in React: graphs, pie charts and tank visuals, each linked to live machine data.
  • Alert notifications back to operators, with the UI wired to the platform APIs.

Results

  • Shop-floor users build their own reports and dashboards from live machine data, without waiting on a developer.
  • Data from machines that speak three different protocols lands in one place, with alerts when something needs attention.
